# kelly.py 口径问题的量化裁决（2026-10-13）

> 状态：**已量化，结论是不改**。本文把这个此前标注"需人拍板"的决定
> 用实测数据关掉，避免后来者重复纠结。

## 问题是什么

`engine/strategy/kelly.py:170`：

```python
market_prob = 1.0 / odds        # 含抽水（竞彩约 8%，实测均值 5.66%）
edge = model_prob - market_prob
if edge < self.min_edge or ev < self.min_ev: continue
```

而系统其它模块用的都是**去水**概率：
- `engine/review/clv.py`（自带 `devig()`）
- `scripts/upgrade_tracker.py`
- `engine/review/post_match.py`
- 账本的 `market_fair` 字段

于是 `min_edge` 的实际门槛是 `0.03 + p_fair × vig`——
p_fair=0.4 的热门，实际要求 `0.03 + 0.4×0.0566 ≈ 0.0526`，比名义值严 1.75 倍；
参数名（`min_probability_edge`）与行为不符。

## 量化结果（账本 1,022 条实测）

| 口径 | 过闸比例 |
|---|---|
| 含抽水（现状 `1/odds`） | **0.00%** |
| 去水（对齐其它模块） | **0.00%** |

**两者都近乎不可达。** 改口径理论上放宽 1.4~2.6 倍，
但基数太小时宽松倍数是假象——放宽 2 倍仍然是 0。

旁证（同批数据）：

| 指标 | 值 |
|---|---|
| `final_prob - market_fair` 中位（按下注方向） | **−0.0050** |
| 正值比例 | **30.0%** |
| ≥0.03 比例 | **0.00%** |
| 含抽水 `1/odds` − 去水 `fair` 中位 | **+0.0566**（即平均抽水 5.66%） |

即：**模型在 70% 的场次里比市场差**，与 E0 的 Brier Δ=+0.02018（t=+34.74）
同一方向；在这种前提下，把闸门放宽只会增加负期望的注。

## 裁决：不改，但要留痕

与 `docs/EXPERIMENTS.md` 里 E3 的结论一致：

> 降阈值只是把不可达的闸门强行打开，让系统去下负期望的注。

所以：
1. **不改 `kelly.py` 的行为**（改了会让"闸门"这个安全机制失效）
2. **在代码注释里标明这是有意为之**，附本文引用，避免后来者当 bug 修
3. 测试**刻意不锁死现状**——真要改时应当连同 E3 结论一起改，
   而不是悄悄漂移（这一点 PR#27 已确立，本文沿用）

## 什么时候该重新评估

- 模型相对市场的 Brier 差距收敛到不显著（E0 的 t 值掉到 2 以下）
- 或竞彩水位显著下降（`odds_bands` / `cli` 的 overround 监测到 <5%）
- 或出现新的独立信号源（如 AUT 平局从"候选"升级为"确认"）

届时用 `scripts/ablation_replay.py` 做配对回放再裁决，
**不要**直接改口径跑一天看结果。

## 二、让球给分口径（核心待验证项，已有结论）

**结论：走盘按"未中"处理，得 0 分——不是退款、不是按 1/2 赔率结算。**

证据：莱比锡 1:0 埃因霍温。莱比锡让 1 球，让球后比分 0:0 = **走盘**，
我们提"让负(-1)"。系统判 **未中、0 分**。

这意味着：
- 我们模型给这场 `p=0.68`（5 注里最高）、EV=+0.69（最高），
  但走盘在挑战规则下与"判错"同价 → **让球票的 EV 计算高估了走盘场次的价值**
- 竞彩实战里走盘是退本金（相当于 0 收益但保本），挑战是 0 分（损失机会成本）
- **修正方向**：让球候选的 EV 应把"走盘概率"单列，
  `EV = p_win × (odds−1) − p_lose`，走盘概率不计入收益——
  这与 `engine/strategy/handicap_ev.py` 现有口径是否一致需复核（大概率不一致）

## 四、口径混淆的实锤（比 EV 更值得修）

命中的两注全是 **JC_SPF（竞彩胜平负）**，丢的三注里两注是 **JC_RQ（竞彩让球）**。
而我们的 EV 计算用的是**欧赔口径的模型概率 × 竞彩赔率**——两个市场水位不同
（竞彩 ~12% vs 欧赔 ~3-5%），这个乘积本身就偏乐观。
`matchPool()` 已正确选择了竞彩口径的**赔率**，但**模型概率仍是欧赔市场训练的**。

# 评测层（Eval Plane）

> 与输入层同构的多源冗余管道：输入层用 欧盘/亚盘/大小球/DJYY/账本 支撑**预测**；
> 评测层用 六席裁判 支撑**判断"预测行不行"**。两条管道物理分离，各自不依赖对方活著。

## 席位表（data/state/eval_registry.json 实时播报）
| 席位 | 性质 | 审什么 | 失联后果 |
|---|---|---|---|
| ledger_clv | 主审·永久 | 全量结算池 Brier/CLV vs 市场 | 周检红牌 |
| tracker | 主审·永久 | 配对 Δ vs 自身冻结基线/市场 | 周检红牌 |
| edge_calib | 陪审·永久 | 分桶 EV 兑现率 | 降级 |
| aut_paper | 陪审·永久 | 候选策略纸面证据 | 降级 |
| challenge | 陪审·**临时** | 预登记池独立镜（站点下线即退席） | 记录退役，系统无恙 |
| djyy_panel | 外援·临时 | 120k 场对手引擎对比 | 同上 |

## 接入协议（热插）
新裁判只需：①往 data/state/ 写一个符合 `samples/verdict` 可提取约定的 JSON
②在 scripts/eval_plane.py 的 JUDGES 加一行。核心引擎不感知，周检自动纳席。

## 宪章
1. 评测层**只读**引擎产物，引擎**永不**读评测层（tests/test_challenge_firewall.py 同源守卫）
2. 模型进化只吃 训练数据管道（账本/CLV/收盘价）；评委席的合议意见进人眼与策略层，不进梯度
3. 临时席位死亡=席位表状态变化，**不是事故**；主审席位死亡=doctor critical（这才是事故）
